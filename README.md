# Installation Instructions

## Running the game

1. Go to the latest release page:
   - GitHub → Releases → Latest

2. Download the build for your platform.

3. Extract the `.zip` file.

4. Open the extracted folder.

5. Run the game:
   - **Windows:** `RatSamurai.exe`
   - **Mac:** `RatSamurai.app`


## Opening the project in Unity

### Requirements
- Unity v.6000.2.8f1
- Git

### Installation
1. Clone the repository:
   git clone https://github.com/Rats-Incorporated/2D-Game-Dev.git

2. Open the project in Unity Hub.

3. Load the Title scene.

4. Press Play.

### Build
1. File → Build Settings
2. Select Windows
3. Click Build


# Controls

## Keyboard & Mouse
- ASD — Move left, down, and right respectively
- Space — Jump
- J — Main Attack with sword swipe
- M — Hold to Charge and release flurry rush 
- N — Alt Attack with sword swing
- K — Throw shuriken
- Left Shift — Dash
- E — Press/Hold to Interact
- Esc — Pause Menu
- Enter — Board Train

## Controller
- Left/Down/Right Gamepad — Move left, down, and right respectively
- X — Jump
- Right Trigger — Main attack
- Right Bumper — Hold to Charge and release flurry rush
- Circle  — Alt Attack with sword swing
- Square  — Throw shuriken
- Square — Press/Hold to Interact
- Left Bumper — Dash
- Esc — Start Button
